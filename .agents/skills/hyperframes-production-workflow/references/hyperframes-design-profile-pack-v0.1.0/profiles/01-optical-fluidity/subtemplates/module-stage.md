# `module_stage`｜模块讲解台

## Use when

Use for a list, tool set, course or repeated comparison whose peer items share one explanation pattern.

## Presentation direction

- Keep one recognizable explanatory stage across peer chapters so viewers can compare and scan without relearning the layout.
- Make the current chapter unmistakably primary while completed context remains subordinate and readable.
- Preserve stable spatial anchors for chapter identity, explanation and overall progress without forcing a specific UI component.
- Let each chapter vary its internal visual treatment according to meaning while retaining the shared stage and hierarchy.
- Use media only when it makes the current explanation more concrete; exact text, data and interface labels remain deterministic.
- Default to `4:3` for a centered, compact information field with depth and deliberate surrounding space.

The ratio is a default mapping, not this subtemplate's identity. An explicitly requested ratio may adapt the same presentation direction without switching subtemplates.

## Ownership boundary

This file defines presentation architecture only. It does not prescribe cards, panels, rails or other component types; nor does it fix component appearance, measurements, reveal order, motion choreography, timings or implementation. Resolve those in the approved Animation Plan through the separate component Skill/library.
