# `hero_flow`｜主视觉叙事流

## Use when

Use for a story, claim, case or process whose visual emphasis changes with each semantic turn.

## Presentation direction

- Give each Scene one distinct semantic Hero rather than repeating one layout shell.
- Maintain spatial continuity across Scenes so the video reads as one developing visual argument.
- Use the full canvas as a layered field with one clear claim, one focal state and only the evidence needed to support it.
- Let composition change with meaning while the shared Profile preserves color, typography, material restraint and hierarchy.
- Treat real media as evidence for the current claim, not as decorative background or a permanent dashboard.
- Default to `16:9` for wide asymmetry, lateral relationships and image/text counterpoint.

The ratio is a default mapping, not this subtemplate's identity. An explicitly requested ratio may adapt the same presentation direction without switching subtemplates.

## Ownership boundary

This file defines presentation architecture only. It does not prescribe component types, component appearance, measurements, entrance or exit patterns, transitions, timings or implementation. Resolve those in the approved Animation Plan through the separate component Skill/library.
