# Profile Selector

Use this before generating the Animation Plan.

| Content intent | Default recommendation | Avoid when |
|---|---|---|
| Software, AI, product demo, architecture, systems, data relation | `optical_fluidity` | The desired tone is literary, archival or deliberately tactile |
| Commentary, research, philosophy, reading, history, long-form explanation | `kami_editorial` | The source footage is already very warm/busy and no clean paper region is possible |
| Brand statement, launch, fashion, climax, concise concept, premium positioning | `monochrome_atelier` | The segment requires dense simultaneous variables or many small labels |

Decision rules:

1. Explicit user choice always wins.
2. Select based on the segment's communication job, not the product category alone.
3. Do not switch Profile within one video unless the user explicitly approves a chapter-level identity change.
4. If a single video contains mixed content, keep one Profile and vary density, not identity.
5. State the selected Profile and one-sentence reason in the Animation Plan.
