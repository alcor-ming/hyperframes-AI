## Visual Identity（统一 Profile 版）

本任务必须从以下三套 Profile 中选择且只选择一套。Profile 控制视觉身份；模板控制画面占用方式。

- 口播增强模板：人物和原视频始终优先，Profile 仅映射为解释层。
- 纯 HyperFrames 模板：Profile 可以控制完整画面，但同一时刻仍只有一个主焦点。

### Profile 1：Optical Fluidity｜光学流动

核心：用空间连续性、即时聚焦和轻量光学材质解释信息；玻璃只承担层级，不作为画面主题。

- 背景：冷调石墨蓝黑 `#0F1216`
- 面板：L1 `#161A21`；浮层/选中态 L2 `#1B1F27`
- 描边/网格：`#272D38`
- 文字：主 `#E8EAEE`；次 `#9AA3B2`；弱化 `#5C6572`
- 主强调：电青 `#5AC8FA`，承担约 80% 的数据、标签、印章与路径强调
- 辅强调：琥珀 `#E8B563`，仅用于少量徽章或 REUSED 印章
- 用色：单帧最多两种强调色，总强调面积低于 5%；不增加高饱和章节色
- 材质：每场最多一个主要玻璃表面；禁止在人脸区域使用玻璃或背景模糊
- 字体：中文 PingFang SC / Microsoft YaHei / Noto Sans CJK SC；英文系统无衬线
- 动词：Focus、Align、Connect、Resolve、Refract
- 运动：直接、连续、无无意义弹跳；路径必须在端点出现后建立
- 禁止：满屏玻璃、嵌套玻璃卡片、霓虹赛博朋克、扫描线、紫蓝 AI 渐变、持续漂浮、大面积动态模糊

### Profile 2：Kami Editorial｜纸上编辑

核心：让信息像一页经过编辑的文章逐步成形；暖纸为底，墨蓝为唯一主强调，排版承担层级。

- 背景：暖羊皮纸 `#F5F4ED`
- 纸面：象牙白 `#FAF9F5`
- 主文字：暖近黑 `#141413`
- 辅助文字：`#3D3D3A` / `#504E49`
- 唯一主强调：墨蓝 `#1B365D`，画面占比不超过 5%
- 字体：中文标题 Source Han Serif SC / Noto Serif CJK SC；中文正文 Source Han Sans SC / PingFang SC；英文 Charter / Source Serif 4
- 动词：Compose、Reveal、Annotate、Rule、Turn、Settle
- 运动：按短语或信息组揭示，建立后留出安静阅读时间
- 禁止：Claude 橙作为固定品牌色、冷灰卡片、玻璃与霓虹、复古手账、硬阴影、页面翻转、普通正文逐字打字机
- 字体许可：不得打包或默认依赖 TsangerJinKai02

### Profile 3：Monochrome Atelier｜黑白工坊

核心：通过删减、排版、留白和精确时机，让极少的信息获得最大重量；高级感来自编辑判断，不来自黑金装饰。

- 背景：带暖调近黑 `#11110F`
- 主文字：暖白 `#F4F2EB`
- 辅助文字：`#A09C92`
- 可选点睛：香槟金 `#C7A66B`，画面占比不超过 1.5%，可完全不用
- 字体：短标题可用 Source Han Serif SC / Libre Bodoni 类高对比衬线；正文使用稳定无衬线
- 强制设计门：Distill → Quieter → Typeset → Layout
- 动词：Isolate、Unveil、Cut、Condense、Lock
- 运动：少而精确，允许果断切换和较长静止；禁止弹跳和弹性
- 禁止：黑金卡片网格、满屏金边、金属渐变、发光、玻璃、嵌套卡片、超细中文正文、所有场景都缓慢淡入

### Profile 共用规则

- 不得混用不同 Profile 的颜色、字体、材质和标志性动效。
- 同一时刻最多 1 个主焦点和 1 个辅助信息组。
- 先建立可读的静态 hero frame，再设计进入动画。
- 人脸、主体和已有字幕区域为保护区。
- Animation Plan 必须列出所选 Profile、hero frame、运动动词、时间范围、风险和测试。
- 未经用户再次明确确认 Animation Plan，不得进入实现和正式渲染。
