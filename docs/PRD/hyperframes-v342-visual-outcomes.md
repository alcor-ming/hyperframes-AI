## 3. 规则条款（当前范围）

唯一结果标准放在 `visual-design.md`；其他文件只引用或说明阅读区域稳定。每条可按上下文微调措辞，不改变语义。

### A1 上屏提炼（替换「叙事模式」中上屏文字段落）

Scene 新增的解释性上屏文字应提炼为支撑观看任务的关键信息或关系，不得把口播或原稿整段复制，也不得以保留相同铺陈的拆行、拆卡、逐句揭示或少量换词规避。提炼不得改变结论，或遗漏必要条件、单位、比较对象与归属。专有名词、数据、确有逐字必要的定义与引语、真实素材原生文字可按最小必要范围保留并沿用现有来源引用，该例外不覆盖周边说明或整段口播。

边界：

- 对象区分口播原文（`verbatim` 不改）、Scene 新增解释文字（受 A 约束）、真实素材原生文字（保持证据原貌，只核验选取区域和用途）。`verbatim` 不是整段上屏许可。
- 提炼不等于必须换词；从长段选取一句已准确简洁的结论本身是提炼。
- 不得把原稿做成图片规避 A；未识别的图片文字不默认通过。
- 条件较多的数据/解释卡不以压短为由删条件、单位或归属。

### B1 持续视觉变化（替换「时长与动作」及辅助图形冲突段落）

视频正常播放期间，最终合成画面应持续存在目标观看尺寸下可感知、服务信息表达或节奏的视觉变化，开场、场内及跨 Scene 交接均不得出现整画面静止等待。正文、数据和证据区域可以保持稳定可读，但这不豁免整画面的持续变化，亦不要求变化新增主张或采用固定数量、方式和频率。隐藏或离屏动作、空 tween、肉眼不可辨变化、无节奏作用的装饰及伪造的进度或执行结果，不计为满足本条。

边界：

- 阅读对象豁免运动，整画面不豁免；不得为 B 让正文漂移、模糊、被遮挡或读不完。
- 真实视频、人物细微动作等非 GSAP 动态可满足 B；没有 tween 不判失败，存在 `<video>` 也不自动通过。
- 慢速但可感知的变化不因速度慢或 tween 少失败；一个持续合适的动作可覆盖较长区间。
- 有意定格、黑场、全屏静态证据页不自动豁免；确有必要时只在原有方向确认中写明该作品的具体例外区间，不新增审批。
- A、B 冲突时调整画面组织，使文字稳定可读与整体视觉连续同时成立，不删必要文字、不保留整画面等待。
- 保留辅助图形创作自由：节奏、氛围和视觉连续性是有效作用，不要求每个动作新增知识。保留“不按动作数量/频率打分”。

### Q1 Draft QA（并入 `hyperframes.md`「Draft QA」）

沿用现有 Draft QA，对照来源与实际可见文字核验提炼和必要信息完整性，并在准确 Studio Draft 中连续观看，核验持续视觉变化、可读性和声画含义。文本相似度、timeline 空档和画面采样只定位候选问题，未覆盖范围标未验证，不以工具 PASS、tween 数量或像素变化代替观看判断。确认缺陷阻止该版本作出相应 QA 通过和接受就绪声明，但不阻止保存、打开与继续修复 Draft，沿用原有方向确认、准确 Draft 接受及无导出边界。

具体诊断数值只写在工具参数说明，不写成导演公式。

## 4. 辅助诊断（当前范围）

两项诊断都由 WSL Harness 提供，在 Windows 对准确 Work/Variant/Draft 运行；只读 Work，不写 Plan、接受状态或 Final，不导出视频，不建立第二份正文数据库。输出定位到准确版本、Scene、文本或时间范围及对应来源，写入现有 QA 记录或命令输出；覆盖不到的范围显式列为未验证，不报告全覆盖。入口挂在既有 Work CLI 的 preview/QA 能力下，具体命令名在实现时确定并写入可执行帮助。

已实现入口：先以既有 `preview open <target>` 打开准确目标，再运行 `work --work <id> --variant <id> preview diagnose <target>`；目标为 `current` 或登记 Draft ID，报告到命令输出。复用锁定 HyperFrames 的 puppeteer-core/sharp，不新增依赖。当前嵌套子画面时钟、无法确认的媒体映射、图片文字和采样间状态明确未验证，不据此宣布完整作品通过。

### D1 上屏文字照搬定位

- 输入：登记 Draft 使用同版冻结 Script/Research/Plan 与 source snapshot；当前可编辑工程固定本次文稿与工程摘要，诊断期间输入变化则结果标过期。与当前 Plan 的差异单列为跨版本差异，不算旧 Draft 缺陷。复用现有 input_sha256、snapshot_sha256，不另建版本系统。
- 文字来源分两层：Scene 源文件与数据文件静态提取；在 Studio 中按实际显示状态读取可见 DOM/SVG 文字（可复用 `tests/visual-studio.mjs` 的读取/定位方法）。隐藏节点、注释、未显示候选不当作上屏。
- 初始参数（可配置，非质量结论）：中文解释性上屏单元在剔除明确例外片段后至少 20 个有效字符，连续匹配或有序匹配覆盖率达到 80% 时标记“疑似照搬”；算法须覆盖分散少量换词，不能只用最长连续片段。
- 聚合优先复用信息 ID、来源与既有 Scene 引用，跨显示时刻去重后按阅读顺序对照；没有可确定映射则保留 Scene 级疑点并标待人工核验，不猜测语义关联。例外须有准确文字片段及来源/人工确认依据，不由“定义”等标签自动豁免；可通过命令参数提供本次已确认例外，不新增 Plan 必填列或正文库。例外“放行”仅指不产生照搬告警，不代表质量通过。长短结论均适用这一边界。
- 归一化只处理空白与一般标点；否定词、数值、单位、数学符号另列为需语义核验。
- 同时报告“Plan 已提炼、实现仍用旧文案”的偏离。
- 伪元素、Canvas、图片/视频内文字、动态生成未覆盖时列为未验证。
- 超阈值不自动判错，低于阈值不自动通过。

### D2 整画面静止定位

- 在 Studio 成片区域跨时间采样（通过现有宿主 seek，不引入第二播放时钟），覆盖开场、场内和跨 Scene 交接；截图排除 Studio 控件、鼠标和播放条。
- 截图前须确认宿主时间、资源和相关媒体已就绪；加载、seek 超时或无法确认的区间标未验证，不把旧帧/黑帧算静止。报告实际采样时间、显示尺寸、参数、缺失区间；有限采样不声称覆盖所有显示状态。
- 初始告警窗口：连续 2.0s 内多个采样点无可感知变化即标记疑似静止；疑点加密并错开相位采样，降低周期运动误判。
- 辅助读取已构建 timeline 的动作区间、目标属性和可见性，标出空 tween、只在开头运动、未覆盖区间；该项只作解释线索，不单独裁决。
- 可感知变化阈值排除像素噪声；小角落闪动、隐藏/离屏对象变化不计为变化。
- 2.0s 不是允许静止 1.9s 的许可；低于窗口的明显等待仍由观看判断。
- 不直接运行整个 `tests/visual-studio.mjs`：其后段调用视频渲染与文件型登记，诊断入口必须隔离导出路径。
