# 数学思维系列

系列 `spec=math-rap` 仅用于 `mode=explainer`，字幕必须开启并显示人工校对的说唱歌词。主载体为数学图解，覆盖 D14：不要求角色或生图。采用时冻结系列身份、版本与规格；后续系列编辑不追改旧 Variant 或接受快照。旧 Variant 无规格时不静默迁移，需要新采用 Variant。

Research 使用 `MATH_RESEARCH.template.md`，记录原片出处、原作者、所用片段及声音来自原片的事实。工具不检查账号或声音来源，不新增音频门禁；正式发布的音频由用户自行处理。原片画面只作结构参考，不复制进工程。

时间依据沿用正式音频与人工校对 Script：共享 ASR 按字符对齐，未对齐字明确报告、不插值。节拍网格绑定正式音频摘要，必须显式提供每小节拍数与首个强拍索引；弱起不默认为第一小节。小节和拍从 1 编号，缺拍号/强拍、无效或越界查询报错，不猜测。锁定版本无法提取拍点时报告限制，不升级依赖或自制提取器。

Plan 逐 cue 写数学单元的保留、揭示、移除与图形职责；符号表记录面积、长度、单位块、份数、未知数方块等画面形象，同一符号全片一致。不变量写等号位置、公式槽位及块内值/块外份数或总量等本片规则；零基础核对逐关系注明可见动作，不用“公式已写出”替代解释。检查缺图形职责、符号形象不一致和收尾超过 2 秒无事件。数学积木及自动挂载不在本轮实现范围。

`units.graphic` 使用符号表中对应形象的相同名称，保证同符号的多个单元可机械核对；具体动作及解释放在 cue 与零基础核对中，而不另起形象名称。

每个 `## S01` 这样的 Scene 节内恰好一个 `math-plan` JSON 块；以下示例按真实 Script cue 和图形替换，不添加未支持字段。`units.id` 在场内唯一，`symbol` 指向 `symbols`；`keep` / `reveal` / `remove` 只引用本场单元且同一行互不重复。`cue` 沿用既有歌词 cue 格式，不自行填写插值时间。缺少 `graphic` 说明不能用空字符串规避检查。

```math-plan
{
  "units": [{"id": "U01", "symbol": "x", "graphic": "未知数方块"}],
  "symbols": {"x": "未知数方块"},
  "invariants": ["等号固定位置，不因揭示新项居中重排"],
  "zero_basics": [{"relation": "同一个未知数保持相同含义", "action": "保留同一方块，仅揭示其边长标注"}],
  "cues": [{"cue": "未知数", "keep": [], "reveal": ["U01"], "remove": []}]
}
```

Research 的原片出处与原作者分别填写来源记录和可核对作者，片段用源起止时间与 Script Anchor 对应，声音来源写实际使用原片音轨的事实和当前正式文件；未知项明确写未核验，不伪造许可或作者。来源事实记录不等于发布授权，也不增加工具音频门禁。

## 只读审查

CLI 按声明收集 Plan、指定 Scene 源码、指定时刻截图、原片联系表、歌词字级时间与节拍到 Review；只读输入须在选定 Work 内，输出须在 Review 内，不能用符号链接或路径穿越越界。截图使用现有 Studio 路径，不导出视频。生产根 Opus 只读审查，不修改 Work，也不代替用户观看。

每项证据标明【图】截图可见事实、【码】源码事实或【未实现】尚无实现/证据，不把代码存在说成画面已验证。固定输出如下：
