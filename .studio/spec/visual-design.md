# 视频表达与观看检查

本文件只维护表达规则，不编排生命周期；四阶段与接受边界见 `.studio/workflow.md`。Plan 用它设计，Studio 对同一要求检查实际实现，结果留在现有 Plan/QA，不新增文件或审批。输入仅为当前选材、Script Anchor、实际时间依据、主题、画幅与相关 Scene。IP Beta 按实际美术目标选用，不强套标准两种模式。

## 叙事模式

| 模式 | A-roll 主叙事 | B-roll 辅助叙事 |
|---|---|---|
| 动效主导 | 图标、对象、比较、关系、过程；文字辅助 | 解释卡、真实界面、图片、案例或结果 |
| 文字主导 | 文字卡片排版、装饰及局部强调 | 接管主画面的图片、界面、案例或短动画 |

不强制 A/B 比例或单场时长；A/B 是叙事职责，不是固定媒体格式，同框装饰不自动算 B。动效主导不强制每场演绎机制；文字主导可按内容使用图文混排或稳定正文。SVG/icon/图片可担当主体、证据或装饰，不要求每个元素提供独立主张，不因“反 PPT”禁止表格、列表、截图或稳定正文。

默认带声连续观看、手机等效尺寸清晰，不要求静音复述全部论证。保留原口播和原总时长；口播原文（包括 `verbatim`）、Scene 新增解释文字与真实素材原生文字分别处理。Scene 新增的解释性上屏文字应提炼为支撑观看任务的关键信息或关系，不得整段复制口播或原稿，也不得以保留相同铺陈的拆行、拆卡、逐句揭示或少量换词规避。提炼不得改变结论，或遗漏必要条件、数值、单位、比较对象与归属。制作约束不改写成观众正文，无增量重复直接删除，可选说明为空就省略；必要来源、对象、条件和导航保留。新数据、比较、因果有来源，真实录屏、模拟与概念示意分清。

文字主导默认以卡片组织信息，不默认大字口播；定义、数据、对比、步骤和清单按内容选用，不统一卡数或比例。卡片可包含图标、数字、简图和媒体，不把这些全部排到 B-roll。避免同构不等于减少卡片。专有名词、数据、确有逐字必要的定义与引语可按最小必要范围保留并沿用来源引用，例外不覆盖周边说明或整段口播。提炼不等于必须换词，从长段选取一句已准确简洁的结论本身是提炼；不设机械字数上限，不为压短删必要条件。`verbatim` 保留原文不等于整段上屏许可。真实素材原生文字保持证据原貌，只核验选取区域和用途；不得把原稿做成图片规避提炼，未识别的图片文字不默认通过。

原稿已有数字、比例和评分比喻允许按原意上屏，不以额外核验或本地实测为前置。未核验不等于已验证：不加“实测”、虚构样本/来源，不将主观比喻转换成客观性能测量；图形不增加原稿没有的精度或比较结论。明显事实冲突保留内部定位和影响说明，不自动删数字或插入免责声明；新增事实、数据和因果仍须有依据。仅对关键遗漏说明原因，不逐句记账，不用关键词检测冒充人工内容验收。

## 图文互补与辅助图形

文字与 SVG/icon 互补，但图形服务本段观看任务，不为填空而新建对象；动效主导同样保留必要定义、标签、条件和结论。主体图形的语义、关系和关键变化由 Plan 明确；普通 icon、小插画及装饰 SVG 由 Scene 制作者按需选用、组合和调整，不逐图审批、不逐项写入 Plan。文字可持续阅读，阅读区域稳定不豁免整画面的持续变化；不设图标数量、覆盖率或每两秒一次动作的机械配额。

正文需要稳定阅读时保持清晰；读完可按舞台编排移动、归组或退出。辅助图形有实际观看任务时承载必要变化，不为持续活动而活动；文字仍可按 cue 揭示和局部强调。优先复用现成对象和动作，不复制整页构图；没有匹配资源时由 Windows 在 Work-local 或可编辑 AssetSource 制作，不虚构已接纳对象。图标组、文档/书页组、终端/浏览器小插画和大幅裁切 SVG 都是内容制作方向，不是 WSL 随工具包交付的四类预设。

不能为了加图损伤已批准内容、缩字、遮挡、挤动仍在阅读的内容或压缩阅读时间；允许不改变结论的等义提炼，并同步 Plan 实际表达。阅读区域保持稳定，节奏、氛围和视觉连续性可以是辅助图形的有效作用，不要求每个动作新增知识。不得伪造执行结果、提前揭示后文或循环重播完成勾选、结果出现、进度到终点。动作限定在场景占用区间并跟随宿主唯一时间线，顺播、直接跳到中段和回拖结果一致，实例清理不影响其他对象。

## 语义揭示与累积

以**最小完整语义单元**组织标题、第一条、下一条；长观点可拆成多个完整意思，不默认逐字打字机或整段揭开。为每项定位口播首次表达该含义的短句或核心词，按其**实际起点**快速出现。“完整”约束语义对应，不等说完整句，也不能因前面出现相关词提前揭示后文结论。新事实、条件和结果即使由图形表达也不能提前泄露；已知对象和中性空间可提前组织。

沿用 Script Anchor、字词定位、正式音频及 section_map；预算不是逐项时间戳，不按 Scene 总时长均分，不对缺失对齐猜测插值。含糊处局部核验。等义精简与选材自由保留，不要求每句 Script 上屏。

同卡仍需阅读的文字保留**内容、位置和可读性**；布局先预留累积空间，新条目不得挤动旧文字。读完可移动、归组或退场，不要求全场只增不减。强调可迁移，上一条恢复正常正文，当前条下划线/加框，不把仍需阅读的文字淡到不可读。容量不足按语义拆成多个场景，不靠缩字、挤装饰或提前清除未读内容硬装。一个 Script 段落可跨多个 Scene，保留原声和源对齐。

## 场景策略

Plan 按段选择，可组合，不要求三种全用、不新增审批，也不强制每次 A/B 切换新建工程 Scene。

| 策略 | 编排 | 必须重建的状态 |
|---|---|---|
| 顺序推进 | Scene 不重复，依次展开 | 新 Scene 逐步建立标题及语义单元，不一次铺满 |
| 切出返回 | A → B → A | 返回恢复离开时已有内容，不重播旧文字入场；未讲内容继续跟随口播 |
| 同场叠层 | B 在顶层接管，A 虚化退后，结束恢复 | 下层保留已有内容，虚化期间不新增必读正文；当前新增信息由清晰顶层承载 |

同场叠层明确接管区间，若新观点必须回到卡片，应提前结束 B 或调整编排，不能在隐藏下层新增正文后假定观众已经读过。任意 seek、回拖与跨 Scene 进入时，文字累积、强调、返回和叠层状态须与顺序播放一致，不只靠播放回调维护。

## 时长与动作

视频正常播放期间，最终合成画面应持续存在目标观看尺寸下可感知、服务信息表达或节奏的视觉变化，开场、场内及跨 Scene 交接均不得出现整画面静止等待。正文、数据和证据区域可以保持稳定可读，但不豁免整画面的持续变化，亦不要求变化新增主张或采用固定数量、方式和频率。先看完整段落和语义分布，再安排已有 Research 的相关例子/图像/B-roll、当前关键词或对象变化；无新信息时仍可持续阅读或观察，不提前揭示下一条、加空话或剪原音。

简单入场、画线、切换按动作本身的自然速度快速完成，不能按剩余口播时长拉伸。隐藏或离屏动作、空 tween、肉眼不可辨变化、无节奏作用的装饰及伪造的进度或执行结果，不计为持续视觉变化。不为持续变化让正文漂移、模糊、被遮挡或读不完；不默认新增 BGM/SFX。

**语义揭示与停留期活动独立检查**：真实视频、人物细微动作等非 GSAP 动态也可满足持续变化，没有 tween 不判失败，存在 `<video>` 也不自动通过。慢速但可感知的变化不因速度慢或 tween 少失败，一个持续合适的动作可覆盖较长区间，不按动作数量/频率打分。有意定格、黑场、全屏静态证据页不自动豁免；确有必要时只在原有方向确认中写明该作品的具体例外区间，不新增审批。提炼与持续变化发生冲突时调整画面组织，使文字稳定可读与整体视觉连续同时成立，不删必要文字、不保留整画面等待。人工检查完整观看过程与声音对应，tween 数量不证明通过，不宣称已有可靠自动判定或新容差阈值。

## 设计与观看

对象辨认特征、必要关系、起止状态和阅读窗口应可执行，不强迫五阶段、Hero 动词或统一状态公式。并列不硬接成因果，流程保留条件、动作与结果；空间、相机、遮挡、光照联动可内聚，Three.js 只用于确有必要的空间表达，长正文留 DOM/SVG。实测当前字体、画幅、文字与显示尺寸，不设统一字数/结尾停顿门槛。

Studio 实际检查：多观点起点与快速列举；仍需阅读的文字稳定、已读内容可退出；长解释不慢放；三种已采用策略的恢复/遮挡边界；顺序播放与直接 seek/回拖相同。正文阅读期间不可被持续缩放、模糊或遮挡，真实截图不能漏掉需要读的区域。只看首帧、静态拼图、像素变化或代码存在不能证明观感；未听音、缺动态或 Windows 原生证据明确未验证。本次规则调整不增加工具开发的强制视觉验收门槛。

Plan 结果直接改相关设计，Draft 结果定位准确版本/Scene/必要时间范围。检查只覆盖实际使用策略和受影响依赖；PASS 仅说明该对象的当前证据，不等于方向批准或完整 Draft 接受。
