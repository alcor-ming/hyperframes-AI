# 视频表达与观看检查

本文件只维护表达规则，不编排生命周期；四阶段与接受边界见 `.studio/workflow.md`。Plan 用它设计，Studio 对同一要求检查实际实现，结果留在现有 Plan/QA，不新增文件或审批。输入仅为当前选材、Script Anchor、实际时间依据、主题、画幅与相关 Scene。IP Beta 按实际美术目标选用，不强套标准两种模式。

## 叙事模式

| 模式 | A-roll 主叙事 | B-roll 辅助叙事 | A / B 实验起点 | 连续 A / 单次 B |
|---|---|---|---|---|
| 动效主导 | 图标、对象、比较、关系、过程；文字辅助 | 解释卡、真实界面、图片、案例或结果 | 70%–85% / 15%–30% | 15–35秒 / 4–12秒 |
| 文字主导 | 文字卡片排版、装饰及局部强调 | 接管主画面的图片、界面、案例或短动画 | 60%–75% / 25%–40% | 10–25秒 / 4–10秒 |

区间不是倒计时或配额，按内容调整无需解释偏离；同框按主要观看任务计时，不重复累计，同框装饰不自动算 B。A/B 是叙事职责，不是固定媒体格式。动效主导不强制每场演绎机制；文字主导大部分卡片有装饰，允许短暂纯文字。SVG/icon/图片可担当主体、证据或装饰，不要求每个元素提供独立主张，不因“反 PPT”禁止表格、列表、截图或稳定正文。

默认带声连续观看、手机等效尺寸清晰，不要求静音复述全部论证。保留原口播和原总时长，但不逐句上屏；可省略铺垫、情绪、衔接及同义重复，不遗漏改变结论的条件。制作约束不改写成观众正文，无增量重复直接删除，可选说明为空就省略；必要来源、对象、条件和导航保留。新数据、比较、因果有来源，真实录屏、模拟与概念示意分清。

文字主导默认以卡片组织信息，不默认大字口播；定义、数据、对比、步骤和清单按内容选用，不统一卡数或比例。卡片可包含图标、数字、简图和媒体，不把这些全部排到 B-roll。避免同构不等于减少卡片。屏幕优先结论及改变含义的条件，设问、铺垫、转折和同义解释通常留在声音；原句适合定义、关键结论或引用时可保留，不设机械字数上限。

原稿已有数字、比例和评分比喻允许按原意上屏，不以额外核验或本地实测为前置。未核验不等于已验证：不加“实测”、虚构样本/来源，不将主观比喻转换成客观性能测量；图形不增加原稿没有的精度或比较结论。明显事实冲突保留内部定位和影响说明，不自动删数字或插入免责声明；新增事实、数据和因果仍须有依据。仅对关键遗漏说明原因，不逐句记账，不用关键词检测冒充人工内容验收。

## 图文互补与辅助图形

文字与 SVG/icon 互补。文字主导默认从图文混排开始，图形不是文字铺满后的补空白；动效主导同样保留必要定义、标签、条件和结论。主体图形的语义、关系和关键变化由 Plan 明确；普通 icon、小插画及装饰 SVG 由 Scene 制作者选用、组合和调整，不逐图审批、不逐项写入 Plan，未列出不表示可以省略。允许有意的短暂纯文字状态，不设图标数量、覆盖率或每两秒一次动作的机械配额。

正文负责稳定阅读，辅助图形在停留期保持适度、可见的活动，主体对象承担关键语义变化；文字仍可按 cue 揭示和局部强调。优先复用现成对象和动作，不复制整页构图；没有匹配资源时由 Windows 在 Work-local 或可编辑 AssetSource 制作，不虚构已接纳对象。图标组、文档/书页组、终端/浏览器小插画和大幅裁切 SVG 都是内容制作方向，不是 WSL 随工具包交付的四类预设。

不能为了加图删改批准文字、缩字、遮挡、挤动已出现内容或压缩阅读时间。活动须发生在可见配图上，不能只动几乎不可见的背景；入场后长时间不动不算停留期活动。允许克制浮动、局部光标或纹理，错开对象，不全体同步晃动；不得伪造执行结果、提前揭示后文或循环重播完成勾选、结果出现、进度到终点。动作限定在场景占用区间并跟随宿主唯一时间线，顺播、直接跳到中段和回拖结果一致，实例清理不影响其他对象。

## 语义揭示与累积

以**最小完整语义单元**组织标题、第一条、下一条；长观点可拆成多个完整意思，不默认逐字打字机或整段揭开。为每项定位口播首次表达该含义的短句或核心词，按其**实际起点**快速出现。“完整”约束语义对应，不等说完整句，也不能因前面出现相关词提前揭示后文结论。概括可由标题/图标先承接，具体观点等各自口播到来再加入。

沿用 Script Anchor、字词定位、正式音频及 section_map；预算不是逐项时间戳，不按 Scene 总时长均分，不对缺失对齐猜测插值。含糊处局部核验。等义精简与选材自由保留，不要求每句 Script 上屏。

同卡已出现文字保留**内容、位置和可读性**；布局先预留累积空间，新条目不得挤动旧文字。强调可迁移，上一条恢复正常正文，当前条下划线/加框，不把旧文字淡到不可读或累积所有强调框。容量不足按语义拆成多个大场景，不靠缩字、挤装饰或提前清除已讲内容硬装。一个 Script 段落可跨多个 Scene，保留原声和源对齐。

## 场景策略

Plan 按段选择，可组合，不要求三种全用、不新增审批，也不强制每次 A/B 切换新建工程 Scene。

| 策略 | 编排 | 必须重建的状态 |
|---|---|---|
| 顺序推进 | Scene 不重复，依次展开 | 新 Scene 逐步建立标题及语义单元，不一次铺满 |
| 切出返回 | A → B → A | 返回恢复离开时已有内容，不重播旧文字入场；未讲内容继续跟随口播 |
| 同场叠层 | B 在顶层接管，A 虚化退后，结束恢复 | 下层保留已有内容，虚化期间不新增必读正文；当前新增信息由清晰顶层承载 |

同场叠层明确接管区间，若新观点必须回到卡片，应提前结束 B 或调整编排，不能在隐藏下层新增正文后假定观众已经读过。任意 seek、回拖与跨 Scene 进入时，文字累积、强调、返回和叠层状态须与顺序播放一致，不只靠播放回调维护。

## 时长与动作

先看完整段落和语义分布，再安排完整语义拆分、已有 Research 的相关例子/图像/B-roll、当前关键词或对象变化；辅助配图及停留期活动按上节作为默认制作职责，不等到没有其他办法才补。无新上屏信息的解释间隔允许正文稳定，不提前显示下一条、不加空话或无依据主张填时间、不剪原音。

简单入场、画线、切换按动作本身的自然速度快速完成，不能按剩余口播时长拉伸。较长动作必须有真实步骤、对象或状态推进；不以慢放、闪烁、无限装饰循环或持续正文漂移冒充内容推进，不默认新增 BGM/SFX。

正文和单个对象可稳定阅读，同时检查实际可感知的停留期活动，不用固定频率制造动作。**语义揭示与停留期活动独立检查**：提前揭完正文再靠装饰运动填时长仍不合格。人工检查可见配图的变化与声音对应，tween 数量不证明通过，不宣称已有可靠自动判定或新容差阈值。

## 设计与观看

对象辨认特征、必要关系、起止状态和阅读窗口应可执行，不强迫五阶段、Hero 动词或统一状态公式。并列不硬接成因果，流程保留条件、动作与结果；空间、相机、遮挡、光照联动可内聚，Three.js 只用于确有必要的空间表达，长正文留 DOM/SVG。实测当前字体、画幅、文字与显示尺寸，不设统一字数/结尾停顿门槛。

Studio 实际检查：多观点起点与快速列举；同卡旧文字稳定；长解释不慢放；三种已采用策略的恢复/遮挡边界；顺序播放与直接 seek/回拖相同。正文不可被持续缩放、模糊或遮挡，真实截图不能漏掉需要读的区域。只看首帧、静态拼图或代码存在不能证明动态通过；未听音、缺动态或 Windows 原生证据明确未验证。

Plan 结果直接改相关设计，Draft 结果定位准确版本/Scene/必要时间范围。检查只覆盖实际使用策略和受影响依赖；PASS 仅说明该对象的当前证据，不等于方向批准或完整 Draft 接受。
