# Baseline evidence

The frozen prototype and its Work keyframes remain the visual evidence for
this first release. They are deliberately not copied into the public package:
the Work snapshots are generated artifacts and may include private media.

The release therefore asserts contract and byte-level integrity here, but does
not claim a new public pixel baseline. Add a sanitized 1440x1080 keyframe only
when a later QA task supplies one and publish it as a new component version if
the frozen visual changes.
