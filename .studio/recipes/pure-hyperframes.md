# Pure HyperFrames Recipe

## 无正式配音

1. 完成文案设计；正文被修改时等待 Script Approval。
2. 根据字数、参考语速和 Scene 信息密度估算时间，生成 Animation Plan。
3. Plan 批准后完成接近 Final 的 HTML 和无声 Draft。
4. 用户接受 Draft 后接收正式配音，生成 `section_map.json`。
5. 从 Accepted Draft 的源码快照继续，只调整时间、停留、转场和元素出现顺序。
6. 无法保持可读性时返回 Draft Review，不改变 Scene 语义或 Hero State 强行压缩。

## 已有正式配音

直接以音频为时间权威生成 Section Map，再完成 Plan、Draft、Final 和自动归档。
