# Pure HyperFrames Recipe

仅记录 `pure_hyperframes` 的结构差异；四阶段、接受与交付见 `.studio/workflow.md`，表达检查见 `.studio/spec/visual-design.md`。

无持续真人主视觉时使用。优先复用正式音频及原字级对齐；无正式音频可按预算制作 provisional 全片 Draft，但不宣称卡点通过。正式音频就绪后仅重定时受影响部分，最终接受不能用无声占位版冒充完整音画基线。

已有正式配音不为静态布局查看强制重新 ASR；工程实际呈现时间与 Script 预算、源对齐分开。人物、图片与视频可按各 Scene 的实际叙事职责出现，不固定全片布局。
